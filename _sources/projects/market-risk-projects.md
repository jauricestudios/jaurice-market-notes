# Market Risk Projects

This page will contain chart-based market risk projects.

The aim is to show how price moves, volatility, spreads and simple exposure tables can be used to understand commodity risk.

## Planned outputs

| Output | Purpose |
|---|---|
| Price return chart | Shows daily or weekly price movement |
| Volatility chart | Shows changing market risk |
| Spread chart | Shows relative value between two markets |
| Exposure table | Shows how a position responds to price changes |
| Simple VaR table | Gives a basic downside risk estimate |
| Stress scenario | Shows what happens under a large market move |

## First build

The first version should use one commodity price series and calculate:

- simple returns
- log returns
- rolling volatility
- basic value-at-risk
- stress move impact

The output should be visual and reproducible.
