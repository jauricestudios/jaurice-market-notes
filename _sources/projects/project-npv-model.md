# NPV Project Model

_Last updated: 17 June 2026_

This page will contain a project finance-style NPV model.

The aim is to value a real asset or commercial project using cash flows, capital expenditure, operating costs, commodity price assumptions, discount rates and scenarios.

## Example use cases

| Sector | Example project |
|---|---|
| Mining | Copper mine expansion |
| Agriculture | Grain storage facility |
| Logistics | Port warehouse investment |
| Energy | Battery storage project |
| Shipping | Vessel or route investment |
| Manufacturing | New processing plant |

## Model structure

| Section | Purpose |
|---|---|
| Inputs | Prices, volumes, costs, capex, tax and discount rate |
| Revenue | Price multiplied by production or throughput |
| Operating costs | Labour, transport, energy, maintenance and storage |
| Capex | Initial investment and replacement costs |
| Free cash flow | Cash available after costs and investment |
| NPV | Present value of future cash flows |
| IRR | Project return estimate |
| Payback | Time to recover initial investment |
| Scenarios | Base, upside and downside cases |

## Outputs

- NPV summary
- IRR estimate
- payback period
- sensitivity table
- tornado chart
- scenario dashboard
- written investment recommendation
