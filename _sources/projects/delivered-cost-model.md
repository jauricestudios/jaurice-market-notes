# Delivered Cost Model

_Last updated: 17 June 2026_

This page will model the full delivered cost of moving a commodity from origin to destination.

The aim is to connect commodity price, freight, storage, FX, insurance, tariffs and delays into one commercial cost estimate.

## Main question

What is the landed cost once freight, storage, FX, port costs, insurance and disruption risk are included?

## Cost build-up

| Component | Example |
|---|---|
| Commodity price | Spot or contract price |
| Freight | Shipping, trucking or rail |
| Storage | Warehouse, tank or terminal cost |
| Insurance | Standard or war-risk premium |
| FX | Currency conversion |
| Tariff | Import duty or trade barrier |
| Port cost | Handling and demurrage |
| Delay cost | Working capital and missed delivery |

## Outputs

- delivered cost bridge
- route comparison table
- freight sensitivity table
- FX sensitivity table
- delay scenario
- margin impact
- recommendation
