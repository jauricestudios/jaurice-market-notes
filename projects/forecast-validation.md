# Forecast Validation

_Last updated: 17 June 2026_

This page will compare forecasts against actual outcomes.

The aim is not to pretend the model can predict the market perfectly. The aim is to test whether the model improves on a simple baseline.

## Checks

| Check | Meaning |
|---|---|
| Naive forecast | Simple benchmark |
| Moving average | Basic smoothing method |
| ARIMA or SARIMAX | Time-series model |
| Actual vs predicted | Visual comparison |
| MAE | Average absolute error |
| RMSE | Penalises larger misses |
| Residual plot | Shows what the model missed |

## Output

The final output should explain what the model captured, what it missed and whether the forecast is useful for commercial interpretation.
