# Scenario Analysis

_Last updated: 17 June 2026_

This page will test how commercial outputs change when market assumptions move.

## Example scenarios

| Scenario | What changes |
|---|---|
| Cold weather | Higher demand |
| LNG disruption | Lower flexible supply |
| Freight spike | Higher delivered cost |
| FX shock | Imported cost changes |
| Storage drawdown | Lower physical buffer |
| Price shock | Margin and exposure change |

## Outputs

- base, upside and downside case
- sensitivity table
- stress table
- chart of key drivers
- commercial interpretation
